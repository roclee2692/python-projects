# 🎮 贪吃蛇游戏 - 全屏和窗口模式使用说明

## 🚀 新增功能

### 1️⃣ **全屏模式** 🖥️
- **进入全屏**：游戏中按 **F** 键
- **退出全屏**：全屏状态下按 **ESC** 键
- **自动适配**：全屏时自动调整到屏幕分辨率

### 2️⃣ **窗口自适应** 📐
- **可调节窗口大小**：在窗口模式下，用鼠标拖动窗口边框可自由调节大小
- **初始窗口大小**：自动计算屏幕80%大小（最大1200×800）
- **实时重绘**：窗口大小改变时游戏内容自动调整

### 3️⃣ **自动获取屏幕信息** 📊
- 游戏启动时自动检测屏幕分辨率
- 根据屏幕大小计算最优初始窗口大小
- 全屏时使用原生屏幕分辨率

## 🎮 游戏流程

### 启动
```
1. 运行游戏
2. 出现难度选择菜单
3. 按 1/2/3 选择难度
   - 1 = 简单 (速度 6)
   - 2 = 普通 (速度 8) ← 推荐
   - 3 = 困难 (速度 10)
```

### 游戏中
```
1. 用方向键或 WASD 控制蛇
2. 按 F 键进入全屏
3. 按空格暂停游戏
4. 在全屏状态下按 ESC 回到窗口
5. 按鼠标拖动窗口边框调节大小
```

### 游戏结束
```
1. 碰撞自己或穿墙时游戏结束
2. 按 C 重新开始（返回难度菜单）
3. 按 Q 完全退出游戏
```

## 💡 功能详解

### 全屏切换机制

**窗口模式 ↔ 全屏模式**

```
按 F 键 (第一次)  →  进入全屏
                      WIDTH, HEIGHT = 屏幕分辨率
                      
按 ESC 键        →  返回窗口模式
                      WIDTH, HEIGHT = 屏幕80% (最大1200×800)
```

### 窗口大小变化处理

当用户拖动窗口边框改变大小时：
- ✅ 实时捕捉 `VIDEORESIZE` 事件
- ✅ 更新 `WIDTH` 和 `HEIGHT` 变量
- ✅ 游戏内容自动重新排列
- ✅ 所有UI元素自适应新大小

### 屏幕信息自动检测

```python
info = pygame.display.Info()
SCREEN_WIDTH = info.current_w    # 屏幕宽度
SCREEN_HEIGHT = info.current_h   # 屏幕高度

# 初始窗口大小 = 屏幕80%，最大不超过1200×800
WIDTH = min(1200, int(SCREEN_WIDTH * 0.8))
HEIGHT = min(800, int(SCREEN_HEIGHT * 0.8))
```

- 可根据需要修改 `BLOCK` 变量

## 🔧 技术细节

### 全屏切换函数

```python
def toggle_fullscreen():
    global screen, is_fullscreen, WIDTH, HEIGHT
    
    if is_fullscreen:
        # 恢复窗口模式
        WIDTH, HEIGHT = min(1200, int(SCREEN_WIDTH * 0.8)), min(800, int(SCREEN_HEIGHT * 0.8))
        screen = pygame.display.set_mode((WIDTH, HEIGHT), pygame.RESIZABLE)
        is_fullscreen = False
    else:
        # 进入全屏
        WIDTH, HEIGHT = SCREEN_WIDTH, SCREEN_HEIGHT
        screen = pygame.display.set_mode((WIDTH, HEIGHT), pygame.FULLSCREEN)
        is_fullscreen = True
```

if event.type == pygame.VIDEORESIZE:

## 🐛 常见问题

**Q: 全屏时游戏画面模糊？**  
A: 这是正常的。如果不满意，可以按 ESC 回到窗口模式，然后手动拉大窗口。

**Q: 能否记住上次的窗口大小？**  
A: 目前没有这个功能。每次启动都是默认大小。可以在代码中添加配置文件来实现。

**Q: 改变窗口大小后为什么蛇还是一样大？**  
A: 蛇的大小由 `BLOCK` 变量决定（固定20像素）。如果想让蛇也自适应，需要修改代码。
