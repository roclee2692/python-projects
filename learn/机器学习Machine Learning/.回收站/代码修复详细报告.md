### 2️⃣ 线性回归/02-代码实现.py
**位置**: `01-线性回归/02-代码实现.py`

**问题**:
- ❌ `plot_predictions`函数无法处理单列特征的情况
- ❌ 使用`plt.scatter(X, y_true, ...)`时，单列X数组会导致问题
- ❌ 无法正确绘制拟合线

**修复内容**:
```python
# 修复前：
def plot_predictions(X, y_true, y_pred, title="预测结果对比"):
    plt.scatter(X, y_true, ...)  # ❌ X可能是单列，格式不对
    plt.scatter(X, y_pred, ...)

# 修复后：
def plot_predictions(X, y_true, y_pred, title="预测结果对比"):
    if len(X.shape) == 1 or X.shape[1] == 1:  # ✅ 处理单变量
        if len(X.shape) == 1:
            X_plot = X
        else:
            X_plot = X[:, 0]
        
        sort_idx = np.argsort(X_plot)
        plt.scatter(X_plot, y_true, ...)
        plt.plot(X_plot[sort_idx], y_pred[sort_idx], ...)  # ✅ 绘制拟合线
    else:  # ✅ 多变量情况
        X_plot = X[:, 0]
        plt.scatter(X_plot, y_true, ...)
        plt.scatter(X_plot, y_pred, ...)
```

**影响**: 现在可以正确绘制单变量和多变量回归的结果

**验证**: ✅ `if len(X.shape) == 1 or X.shape[1] == 1:` 检查已添加

### 3️⃣ 逻辑回归/02-代码实现.py
**位置**: `02-逻辑回归/02-代码实现.py`

**问题**:
- ❌ `evaluate_classification`函数中，当`y_proba=None`时，`auc`变量未定义
- ❌ 返回值中使用未定义的`auc`变量导致NameError
- ❌ 没有处理precision_score、recall_score的zero_division问题

**修复内容**:
```python
# 修复前：
def evaluate_classification(y_true, y_pred, y_proba=None, model_name="模型"):
    # ...
    if y_proba is not None:
        auc = roc_auc_score(y_true, y_proba)  # ❌ 当y_proba=None时，auc未定义
        print(f"AUC: {auc:.4f}")
    # ...
    return {'accuracy': acc, ..., 'auc': auc}  # ❌ 可能auc未定义

# 修复后：
def evaluate_classification(y_true, y_pred, y_proba=None, model_name="模型"):
    # ...
    auc = None  # ✅ 初始化为None
    
    prec = precision_score(y_true, y_pred, zero_division=0)  # ✅ 添加zero_division
    rec = recall_score(y_true, y_pred, zero_division=0)  # ✅ 添加zero_division
    f1 = f1_score(y_true, y_pred, zero_division=0)  # ✅ 添加zero_division
    
    if y_proba is not None:
        auc = roc_auc_score(y_true, y_proba)
        print(f"AUC: {auc:.4f}")
    # ...
    return {'accuracy': acc, ..., 'auc': auc}  # ✅ 现在auc总是被定义
```

**影响**: 函数现在可以在所有情况下运行，无需y_proba参数也不会出错

**验证**: 
- ✅ `auc = None` 初始化已添加
- ✅ `zero_division=0` 处理已添加
